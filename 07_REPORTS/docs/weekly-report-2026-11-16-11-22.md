### 2. Security & Hạ tầng MoMo API (BFF): Module Trace Bug với X-Request-Id, Thư viện `bffClient` và 254 Test Cases đạt 100%
- **Key Owner:** loc.le4 | **Phối hợp:** hieu.nguyen8, thuan.vo, ITC Security Team, DevOps Team

- **Kho mã nguồn:** Dịch vụ BFF Node.js `momo-web-node-function` · Thư viện `momo-fe-share-lib` (`lib/bff/`) · Tài liệu quy chuẩn luồng lỗi BFF (`bff-error-flow.md`)
- **Mục tiêu & Tác động:** Che giấu toàn bộ thông tin nội bộ của Supabase khỏi client nhưng vẫn đảm bảo khả năng truy vết nguyên nhân sự cố phía server; cung cấp thư viện client chuẩn cho lập trình viên Front-end.
- **Tiến độ thực tế trong tuần (loc.le4):**
  * **Xây dựng module Trace Bug cho BFF Supabase:** Mỗi request có `requestId` trả ở header `X-Request-Id` (kể cả khi lỗi, hỗ trợ đọc qua `Access-Control-Expose-Headers`). Phân loại log lỗi `upstream` (Supabase) và `internal` (code route); bug trong route luôn trả mã lỗi 500 kèm `code: INTERNAL_ERROR`, lỗi gốc lưu trong log server; ngắt sớm các truy vấn đứng sau truy vấn lỗi. Bộ test tự động đạt **254/254 test cases (100%)**.
  * **Module `bffClient` cho Client Web:** Xây dựng instance axios chuyên dụng cho browser với kết quả tương thích `supabase-js` (`{ data, error, count, status, statusText }`), tự động chuyển đổi mảng tham số sang JSON an toàn (tối đa 100 phần tử); xử lý CORS theo môi trường và bắt buộc `POST` có `Content-Type: application/json`. Chặn gọi `bffClient` ở phía server (`BFF_SERVER_SIDE_NOT_ALLOWED`).
  * **Bộ tài liệu quy chuẩn AI & Ép quy tắc ESLint:** Soạn tài liệu quy chuẩn giúp AI vibe code an toàn trên BFF (bắt buộc bọc `withApi`, không để client tự chọn `select`/`limit`); cấu hình ESLint chặn vi phạm lúc build.
  * **Xử lý lỗi 404 MoSpark & Whitelist:** Cấu hình Cloudflare xử lý lỗi 404; triển khai whitelist guest cho BU Bảo hiểm.
